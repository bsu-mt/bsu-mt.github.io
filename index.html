RevitQC

pyRevit · Python

A pyRevit extension that adds one-click model-QC tools to Revit's ribbon, built around a Canadian HVAC (mechanical) project naming convention. Automates checks that would otherwise mean manually eyeballing a model:

  • NameChecker — validates HVAC type names (equipment, air terminals, ducts, pipes) against configurable regex rules.
  • SizeChecker — flags duct/pipe sizes that don't match an approved standard sizing table.
  • EquipmentChecker — flags equipment missing a tag, and air terminals missing a tag or with zero/blank airflow.

Each rule set lives in an editable JSON file, and the core checking logic is Revit-independent and unit tested.

RevitWebSocketAddin

C# · Revit API · WebSocket

A Revit add-in that exports the active 3D view to OBJ/MTL and streams the files over a raw WebSocket connection to an external server — built to feed a live Revit model into Unity for visualization.

  • Adds a custom ribbon tab with an Export OBJ command that exports the active 3D view and uploads the mesh/material files in chunks.
  • Includes an experimental second application that keeps an open WebSocket connection for future live document-change syncing.

Pairs with UniWeb on the receiving end.

UniWeb

C# · Unity Package · WebSocket

A Unity package that loads and saves BIM models — including materials — from a WebSocket server, so a model exported from Revit can be streamed straight into a Unity scene without a manual import step.

Built as the Unity-side counterpart to RevitWebSocketAddin, and structured as a drop-in Unity package (Packages/WebSocketConnector) with editor and runtime components.

HoloLens LCA Viewer

C# · Unity · HoloLens 2 · Mixed Reality

A Unity mixed-reality project deployed to Microsoft HoloLens 2 for visualizing a Revit-exported building model in place, with Life Cycle Assessment (LCA) data attached to it for spatial, in-context review.

Built on Microsoft's Mixed Reality Toolkit (MRTK3) with XR Interaction Toolkit support, letting users walk through and interact with environmental-impact data overlaid on the building model in situ.
